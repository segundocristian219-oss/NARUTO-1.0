# Kaede-WaBot
Un bugsito de WhatsApp basado en la libreria `baileys` este bot ofrece gran variedad de comandos listos para usarse y mejorar la experiencia en Whatsapp.

> [!NOTE]
> Este proyecto esta siendo actualizando constatemente, ofrece un pequeño soporte de lids para administradores de grupo, lo cual aun prensenta unos pocos de bugs. Te invito a que te unas a mi [!Canal de Whatsapp](https://whatsapp.com/channel/0029VbB1ujH8qIzjgU3Vul1l)

<p align="center">
Disfruta de este bot totalmente gratuito, de codigo abierto.
</p>

## Funciones
- Comandos Gacha.
- Comandos de economia.
- Gestion de grupos para administradores.

## Comandos de instalacion

Termux:
```bash
termux-setup-storage

```
```bash
apt update && apt upgrade && pkg install -y git nodejs ffmpeg imagemagick yarn

```
```bash
git clone https://github.com/ulises12354/Kaede-WaBot
```
```bash
cd Kaede-WaBot
```
```bash
yarn install
```
```bash
npm install
```
```bash
npm start
```
>  *Si aparece **(Y/I/N/o/D/Z) [default=N] ?** use la letra **y** y luego **'Enter'** para poder continuar con la instalacion del bot.

¿Deseas usar pm2 para mas tiempo activo?

> Importante dentro de la carpeta Kaede-WaBot
```bash
termux-wake-lock && npm i -g pm2 && pm2 start index.js && pm2 save && pm2 logs

```

> Si deseas iniciar denuevo el bot usa:
```bash
pm2 start index

```

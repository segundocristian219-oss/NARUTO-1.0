Preguntas Frecuentes (FAQ)

¿Qué pasa si mi bot se desconecta? ▼

El sistema cuenta con un mecanismo de auto-reinicio automático. Si la conexión se cae por problemas de red o de la sesión, el servidor intentará reconectar el bot por ti de forma automática.

¿Cómo encuentro el enlace de mi canal de WhatsApp? ▼

Entra a tu canal desde la aplicación de WhatsApp, ve a los ajustes o información del canal, haz clic en "Compartir" y selecciona la opción de copiar enlace de invitación.

¿Qué significa que el dueño esté "No verificado"? ▼

Significa que el número telefónico que ingresaste no se encuentra registrado dentro de la base de datos de usuarios autorizados o carece de un nombre asociado. Asegúrate de escribir el número con su formato correcto de código de país.
